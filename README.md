# DashboardPaper
Prints log info on e-paper.
For esp32 and e-paper EPD 7in5b V2.

## Features
- Scrapes data from mounted html file (source code from website);
- Connects to Wifi and downloads website content from webpage (currently download works non-deterministically -> troubles with receiving cookie from server);
- Reads BlackBox data from csv file;
- Prints data to e-paper dashboard;
- Refreshes every specified period.
